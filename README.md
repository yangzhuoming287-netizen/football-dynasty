# 绿茵王朝 · 足球生涯（Football Dynasty）

手机网页足球游戏：**局内实时操控球员踢比赛** + **局外球队经营与转会**。

## 3D 立体模式（v2 新增）

比赛画面使用 **Three.js** 引擎渲染 3D 立体球场：立体球员模型（带跑动摆臂摆腿与踢球动画）、
球门与球网、四周看台与观众、灯塔、阳光投影与阴影、天空与雾气。

- **三种镜头**：转播（侧上方）/ 跟随（球员身后）/ 俯视，底部按钮可切换
- **画质开关**：高（阴影 + 抗锯齿 + 高分辨率）/ 低（省电，适合老手机）
- **2D/3D 切换**：老设备可一键切回原来的 2D 俯视图
- 引擎（Three.js r149，MIT 协议）已内嵌进单文件，**离线也能跑**


## 球员系统（v3 真实数据驱动）

- **数据来源**：FIFA 18 公开数据集（18,147 名球员）统计出的真实分布 —— 按位置×能力档位的属性均值/标准差、
  身高体重、年龄曲线、潜力、惯用脚比例、花式星级分布、国籍占比（24 国）
- **14 项属性**：速度/加速/体能/身体 · 终结/传中/头球 · 传球/视野/盘带/花式 · 抢断/站位 · 守门
- **13 种球员特性**（影响实际比赛，不只是数值）：
  疾风（冲刺+8%）· 铁人（体能消耗-38%）· 组织核心（直塞精度+25%）· 传中专家（落点+30%）·
  盘带大师（推进+10% 被断-15%）· 花式王（过人成功率+35%）· 终结者（禁区射门+30%）·
  空霸（争顶+35%）· 铁闸（抢断+20%）· 门神（扑救+12%）· 领袖（队长）· 新星（成长翻倍）· 老将
- **每人一张唯一头像**：程序化生成（肤色 6 种 × 发型 7 种 × 发色 9 种 × 脸型 3 种 × 胡须 5 种 × 五官），
  约 20 万种组合，不会撞脸
- **3D 模型差异化**：身高（163-205cm 真实换算）、体型（按身体属性）、肤色、发型（寸头/卷发/长发/马尾/爆炸头/光头）、
  **球衣背号**、**队长袖标**

## 比赛动作（v3 新增）

| 按键 | 有球时 | 无球时 |
|---|---|---|
| 传球 | 短传（长按＝**直塞**，精度看视野/组织核心） | 逼抢 |
| 射门 | 射门（长按＝**挑射**；边路靠近底线自动变**传中**） | 头球（球在空中时） |
| 铲球 | **花式过人**（成功率看花式/盘带 vs 对手抢断） | 铲球 |

- **球有真实高度**：重力、弹地、抛物线传中、空中球不能被脚下停住，只能头球处理
- **头球**：传中/长传后禁区内自动争顶，精度看头球属性与空霸特性
- 战报统计新增：传中、直塞、花式成功、头球、抢断

## 玩法
- **生涯模式**：选一支欧洲豪门，带 38 轮联赛；董事会给你定目标（夺冠/前三/前六）
- **局内比赛**：实时 2D 俯视视角，左侧虚拟摇杆控制球员移动，右侧四个按键
  - 传球（有球时按摇杆方向选人，没球时自动变为逼抢）
  - 射门（瞄向两侧死角，距离越远越不准）
  - 冲刺（消耗体力）
  - 铲球
  - 相机跟随球，下半场自动交换场地，支持换人（3 个名额）、暂停、模拟到终场
- **局外经营**：
  - 阵容：5 种阵型（4-4-2 / 4-3-3 / 4-2-3-1 / 3-5-2 / 5-3-2）、自动排阵容、球员详情
  - 转会：搜索/筛选球员市场、自由球员、报价谈判（转会费 + 周薪双滑杆）、收到其他俱乐部报价并决定卖不卖
  - 训练：每周 3 点训练点，年轻球员成长快，30 岁后属性下滑
  - 财政：电视转播费 + 主场门票收入、周薪支出、工资帽、赛季末名次奖金
  - 积分榜、射手榜、历史战绩、赛季结算与推进
- **存档**：3 个本地存档位

## 说明
- 20 支欧洲豪门球队（真实队名），**440 名球员全部程序随机生成**（按国籍风格的中文译名组合，不使用任何真实球员姓名）
- 单文件 HTML，无外部依赖，离线可玩；画面与音效（球场观众底噪、哨声、踢球、进球号角）全部用 WebAudio 实时合成
- 手机浏览器打开即可，建议横屏获得更宽视野

## 技术
- 比赛引擎：105×68 米真实比例球场，逐帧物理（球的摩擦/减速）、22 人 AI（阵型推移、盯人、逼抢、跑位）、
  门将扑救概率模型、出界/角球/门球重启、半场交换场地与进球归属
- 生涯引擎：循环赛程生成、基于球队强度的泊松分布比分模拟、转会市场与 AI 俱乐部交易、球员成长与老化
